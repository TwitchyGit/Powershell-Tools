# Glossary

## Object

A structured value with properties and methods. PowerShell pipelines pass objects unless output has been converted to text.

## Pipeline

A command chain where output from one command becomes input to the next command.

## Fixture

A stable local input file used by a lesson or test. Fixtures make training examples repeatable.

## Receipt

A structured output record that proves what a script attempted and what result it produced.

## Manifest

A structured file that describes package, deployment, backup or configuration content.

## Static check

A check that reads code or metadata without proving live external behavior.

## Smoke test

A fast execution check that proves a script starts, completes and returns an expected process result.

## Live validation

A check performed against the real target platform such as AD, PVWA, AutoSys or Windows PowerShell 5.1.

## Entry script

A runnable script that owns top-level error handling and exits `0` for success or `1` for failure.

## Module

A reusable `.psm1` file that provides functions for scripts to import.
