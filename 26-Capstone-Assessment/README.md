# Capstone assessment

This section combines the course themes into one local readiness exercise.

Run:

```powershell
./Invoke-CapstoneAssessment.ps1
./Invoke-CapstoneAssessment.ps1 -View Detail
```

The lesson reads `fixtures/sample-data.json` and demonstrates:

- validation coverage
- logging evidence
- security checks
- REST handling
- report completeness

The script scores sample records only. It does not collect real submissions or write assessment results elsewhere.
