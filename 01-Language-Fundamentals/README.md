# Language fundamentals

This unit teaches the shape of PowerShell itself: values, operators, control flow, types, classes and small concurrency examples.

Work through the scripts in any order, but start with arrays, comparison, strings, loops and switch before moving to classes, jobs and parallel examples.

Process focus:

- Array scripts show index, slice, paging and final-page behavior.
- Loop scripts show skipped records, stop conditions, indexed attempts and polling.
- Type scripts show casts, type accelerators, enums and class methods.
- String scripts show interpolation, here-strings, regex captures and formatting choices.
- Decision scripts show comparison operators, membership checks, switch routing and ternary use.
- Runtime scripts show strict mode, script scope, background work and parallel runspace output.

Useful checks:

```powershell
./ArrayIndexing.ps1
./SwitchStatement.ps1
./StrictMode.ps1
./ParallelForEach.ps1
```

Training aim: understand why PowerShell treats objects, strings and collections differently before the later units add real files and modules.
