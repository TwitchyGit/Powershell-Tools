# Instructor guide

This guide supports delivery of the PowerShell course samples as a practical training sequence.

## Delivery model

The course works best as eight short labs. Each lab should start with a read-through of one small script, followed by a run, an output inspection and a small learner edit.

## Timing guide

- Unit 01: 90 minutes for language fundamentals.
- Unit 02: 90 minutes for object and data handling.
- Unit 03: 120 minutes for functions and pipeline behavior.
- Unit 04: 90 minutes for files, runtime and local process evidence.
- Unit 05: 60 minutes for modules, configuration and static validation.
- Unit 06: 90 minutes for deployment staging and receipts.
- Unit 07: 90 minutes for directory-service-shaped operational logic.
- Unit 08: 120 minutes for backup, restore, compatibility and CyberArk-shaped records.

## Teaching checks

Ask learners to state:

- Which command produces objects and which command formats objects.
- Which validation happens locally and which requires a live system.
- Which fields prove success and which fields only show a simulated condition.
- Which scripts are entry scripts and which files are modules.
- Why scripts return `0` or `1` only.

## Common mistakes

- Treating formatted output as data.
- Assuming local AD-shaped records prove live AD behavior.
- Assuming parser success proves runtime success.
- Ignoring `$LASTEXITCODE` after native commands.
- Adding comments that restate the command instead of documenting a constraint.
- Writing sample secrets to reusable files.

## Assessment rubric

A pass-level learner can run a script, explain the input, describe the output and identify the validation boundary. A strong learner can extend a script while keeping structured output, predictable errors and documented exit behavior.
